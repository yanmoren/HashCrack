# 内置字典（精简版）

本目录是 HashCrack 附带的**精简字典集**，合计约 **168 MB**。

⚠️ **这里不是完整字典。** 原始字典合计约 40 GB，其中单个文件最大 28.7 GB，
远超 GitHub 单文件 100 MB 的硬上限，无法直接入库。因此大字典都做了精简，
只保留一份可用的样本。完整版请自行获取。

## 怎么用

软件启动时会扫描 **exe 同级目录下的 `runtime\dicts\`**（只扫顶层，只认
`.txt` / `.dic` / `.dict` / `.lst` / `.wordlist`）。把本目录的 `.txt`
复制过去，重启软件即可自动加载：

```
HashCrack\
  HashCrack.exe
  runtime\
    dicts\          ← 把 .txt 放这里（不要放子文件夹）
```

也可以在「设置 → 字典管理」里手动添加单个字典文件。

## 为什么「弱字典」取头部，其它用抽样

- **`弱字典.txt`** 是按**使用频率**排序的，开头就是 `87654321`、`11111111`
  这类最常见密码。所以取头部 20 MB 保留下来的正是命中率最高的部分，
  丢掉的是长尾。
- **`8数字.txt`、`8数字加字符.txt`、`百家姓加年月日.txt`、`2024wifi字典.txt`**
  是按**规则顺序生成**的（如 8 位数字从 `00000000` 递增）。这类字典如果
  只取头部，就只剩 `000000xx` 这一小段，等于没用；所以改用**等步长抽样**，
  让保留的样本均匀覆盖整个取值区间。
